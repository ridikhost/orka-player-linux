OrkaPlayer Linux v2.3 "Cortado"
Port nieoficjalny do aplikacji OrkaPlayer pod Linux napisany w 100% w Rust.
Kompilowanie z źródła:
Klonujesz repo (chyba wiesz jak to sie robi)
jesli masz rusta to wpisujesz
cargo run lub cargo build --release
jesli nie masz to se pobierz
Co działa co nie działa:
Sync Lyrics: Działa
Odtwarzanie audio: Działa
Odtwarzanie wideo: Chyba działa
Odtwarzanie M3U: Nie Działa
Playlisty: Nie Działa
Pauza: Działa
